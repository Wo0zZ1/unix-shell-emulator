# Эмулятор Командной Строки UNIX

[![Electron](https://img.shields.io/badge/Electron-38.0-white)](https://www.electronjs.org/)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.9-blue)](https://www.typescriptlang.org/)
[![Jest](https://img.shields.io/badge/Jest-30.2-red)](https://www.jestjs.io/)

Графический эмулятор командной строки UNIX-подобной оболочки. Разработан в рамках учебного задания по дисциплине "Конфигурационное управление" в РТУ МИРЭА.

## Возможности

- **Графический интерфейс:** Нативное desktop-приложение на основе Electron.
- **Виртуальная ФС (VFS):** Файловая система в памяти, загружаемая из XML.
- **Команды оболочки:** Реализованы команды:

  | Команда    | Описание                          | Пример                 |
  | ---------- | --------------------------------- | ---------------------- |
  | **cat**    | Вывод содержимого файла           | `cat readme.txt`       |
  | **cd**     | Смена текущей директории          | `cd /home/user`        |
  | **clear**  | Очистка экрана терминала          | `clear`                |
  | **cp**     | Копирование файлов и директорий   | `cp file.txt ./folder` |
  | **echo**   | Вывод текста                      | `echo "Hello $USER"`   |
  | **exit**   | Выход из эмулятора                | `exit`                 |
  | **export** | Установка переменных окружения    | `export PATH=/usr/bin` |
  | **grep**   | Поиск текста по шаблону           | `grep "error" log.txt` |
  | **head**   | Вывод первых N строк файла        | `head -n 5 file.txt`   |
  | **ls**     | Список файлов и директорий        | `ls`                   |
  | **mkdir**  | Создание директорий               | `mkdir -p dir/subdir`  |
  | **mv**     | Перемещение/переименование файлов | `mv old.txt new.txt`   |
  | **pwd**    | Вывод текущего пути               | `pwd`                  |
  | **rm**     | Удаление файлов и директорий      | `rm -r folder`         |
  | **rmdir**  | Удаление пустых директорий        | `rmdir temp`           |
  | **savefs** | Сохранение VFS в XML файл         | `savefs snapshot.xml`  |
  | **tail**   | Вывод последних N строк файла     | `tail -n 10 log.txt`   |
  | **touch**  | Создание пустого файла            | `touch newfile.txt`    |
  | **unset**  | Удаление переменных окружения     | `unset PATH`           |

#### 💡 **`TIP`**: Чтобы ознакомиться со всеми возможностями комманды введите её с флагом `--help`. Пример: `tail -h`

- **Настраиваемость:** Поддержка пользовательских приглашений, стартовых скриптов и путей к VFS через аргументы командной строки.
- **Кроссплатформенность:** Запускается на Windows, Linux и macOS.
- **Фичи:**
- - Удобная навигация по истории введённых команд с помощью стрелочек `Up` и `Down`
- - Реализована удобная система автодополнения при нажатии клавиши `Tab`
- - Реализована поддержка переменных окружения в командах оболочки `$VAR`
- - Поддержка конвейеров `|` и перенаправления ввода/вывода `<`, `>`, `>>`

## Установка и Запуск

1.  **Клонируйте репозиторий:**

    ```bash
    git clone https://github.com/your-username/unix-shell-emulator.git
    cd unix-shell-emulator
    ```

2.  **Установите зависимости:**

    ```bash
    yarn install
    ```

3.  **Соберите проект:**

    ```bash
    yarn build
    ```

4.  **Запустите приложение:**
    ```bash
    yarn start
    ```

#### 💡 **`TIP`**: Чтобы ознакомиться со всеми флагами запуска введите команду yarn start --help

### Аргументы командной строки

| Аргумент              | Описание                              | Пример                           |
| --------------------- | ------------------------------------- | -------------------------------- |
| `--vfs-path`, `--vfs` | Путь к XML-файлу VFS                  | `--vfs "VFS.xml"`                |
| `--prompt`, `-p`      | Пользовательское приглашение оболочки | `-p "my-terminal $"`             |
| `--script-path`, `-s` | Путь к стартовому скрипту             | `-s "./scripts/test-script.txt"` |
| `--test-parser`, `-t` | Запустить тесты парсера без GUI       | `-t`                             |

## Разработка

- **Полная сборка:** `yarn build`
- **Запуск приложения в dev режиме:** `yarn start:dev`
- **Запуск тестовых скриптов:** `yarn test:base` или `yarn test:script` или `yarn test:vfs`
- **Запуск тестов jest** `yarn test`
